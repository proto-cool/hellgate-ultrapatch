# 2007 retail vs 2018 Steam: content and English

A comparison of the 2007 retail disc (`ref/retail-2007/Disc01.iso`, v1.0,
Flagship Studios) with the 2018 Steam build (HanbitSoft/T3), made
2026-09-23. It lists what 2018 lost, what it ships broken or unfinished, and
how much of its English is bad, with what each fix would take on the 2018
exe. The working files (per-string verdicts, table row diffs, file lists)
are local only, in `ref/retail-2007/audit/`, because they quote game data.

## Method

- **Paks.** Both builds' indexes decrypt with `tools/data/hgdat.py`
  (`HG_GAME=<dir with data/>` for the disc's `ProgramFiles/Flagship
  Studios/Hellgate London/Data`). 2007: 40,819 files; 2018: 63,933.
- **Strings.** `.xls.uni.cooked` string tables have the same format (v6) in
  both builds: header, then per row id, key, UTF-16 text and attributes
  (layout from Reanimator-steam `StringsFile.cs`). The cinematic table has
  two rows per `_a` key: the text, then a `Timecode` row with the same key.
- **Tables.** 2018 excel tables were fully decoded against the
  Reanimator-steam row classes (every row size matches). For 2007 only the
  row names were compared.
- **English.** All 2018-only and changed English strings in every table were
  read, with heuristics only for triage.

## What 2018 lost

| What | 2007 | 2018 | Restore |
|---|---|---|---|
| **Credits** | 1,473 rows, opening with "The Originators of Hellgate: London" (Brevik, Roper, E. and M. Schaefer, …) | 132 rows, T3/HanbitSoft only, 20 of them "Unknown" | String table only: Flagship's roll back, T3/Hanbit's after it |
| **Flagship logo movie** | `LogoFlagship` row in `movies.txt` | row deleted; the Hanbit logo plays instead | Table row (needs an excel writer), plus the 2007 `.bik`. The Hanbit logo is gone already (below) |
| **HD cinematics** | `scene 1-5/6/7/8_high`, `truth 1-5_high` at 1920×1088, `endcredits_*_high` at 1680×1056 (2.1 GB) | only the `_low` files at 640×368 (byte-identical to 2007's), although 2018's `movies.txt` still names the `_high` ones | **Done** (`make paks`, see below) |
| **Lore blurbs** | long `*_analyze` texts | shortened | Aeron Altair, Doctor Salus, Mary Dotter, Moira Mable and Tiberius verbatim; others only where the NPC is unchanged |
| **Act 2 Temple levels** | 24 level rows | rows gone; the map layouts and rule files still ship | Table rows plus design work |
| **Particle stages** | later blood-hit and get-hit stages, second layer of loot beams | 65 stages trimmed | Cooked-XML writer |
| **3rd-person blends** | 62 animation blends | gone | See backlog H |
| **Voice lines** | 370 English lines | cut together with their `sounds.txt` rows and the 2007 quest text | Only with the 2007 quests; not worth it |

Not losses, although they look like it in a file diff:

- **Cutscene subtitles.** The 2018 English subtitle rows (`movie_subtitles`,
  86 with language 0) all point at the `_a` strings, which are Flagship's
  text with trailing spaces trimmed and `--` set as `—`. The 86
  back-translated `_b`–`_e` fragments in the English file ("The human that
  fights the hell is the hope") are referenced only by the Korean and
  Chinese rows, which read their own languages' strings, so an English
  player never sees them.

- **923 `_normal_bc5.dds` files** are DX10-only copies; a DX9 `_normal.dds`
  exists for 921 of them. The apparently cut weapons, heads and armour are
  these.
- About 150 files moved to another folder or format.
- The DX10 and x64 executables: both builds run a 32-bit DX9 exe.

## What 2018 ships broken or unfinished

- **Placeholder text:** 12 quest-log lines "PLACEHOLDER: …", 12 centaurs
  named "Placeholder for … Centaur", "Sir Placeholder" on 6 staffs, 222
  items reading "need translation", 16 strings in Hangul.
- **Wrong data:** the demon and beast essence altars ask for each other's
  essence; several achievement titles are shifted by a row (the Undead
  achievement grants "Imp killer"); `speed_level_11/12` say "Disassemble";
  `wart_analyze` and `Rusy_analyze` hold other characters' text; quests use
  `[PLAYERNAME]` for `[PLAYER NAME]`; `item list separator` lost its space.
- **Missing textures** the disc supplies: `catacombsenvmap.dds` (6 catacombs
  environments), the Plasma Orb Generator Mk2 skin, `vial_power_diffuse.dds`.
- **Hell Tower elemental levels** name 12 tinted wind, warp and ring-glow
  particles that were never shipped (the untinted ones exist).
- **24 spawn-enabled bosses with no appearance file:** the long-dungeon
  "King of …" bosses, Chimaera, Kaiju Ryuma, Turagami.
- **Silhouette-flames death state:** its material and shader were removed.
- **Loading screens** for the pvp, Stonehenge, cow and base-defence levels
  exist only in widescreen layouts.

Present but switched off: four Guy Fawkes Night quests (GFN1–4) and two
Halloween quests, each behind one flag; about 45 cash-shop costumes and the
All Hallows' Visage, Santa hat and Red Devil helmet, which nothing sells in
single player. `background\tokyo_01` (2,560 files) ships in full; whether it
is reachable in single player is unchecked. Tokyo act 2 onward, the Time
Tunnel and Hellrift levels and 9 duel maps are table rows with no map data:
not restorable.

## English

The 2018 rewrite of the London campaign is fluent (1–2% slips). The bad
English is HanbitSoft's new content. Of the strings 2018 added or changed:

| Tables | Read | Bad | of which placeholder, debug or Hangul |
|---|---|---|---|
| items, skills, affix, monsters, names, displayformat | 3,813 | 1,375 (36%) | 766 |
| quest, strings, common, loadingtips, level, cinematic, install | ~6,800 | ~2,120 | ~110 |

Worst clusters: Tokyo (169 of 231 quest strings bad), the Abyss and
Parliament Square, the HGT new-player tutorial, the Dark Wills chain,
Westminster, achievements (955 of 1,712 bad), cash-shop consumables and
tooltips, the character-sheet tooltips, `tokyo2_*_analyze`. Korean-origin
terms need mapping back to the game's own (Illusion → Spectral, Mentality
and Mana → Power). 155 of the 176 changed skill texts are rebalances and
must stay.

## How fixes ship

- **Strings:** the DLL already answers the string-by-key lookup for our own
  keys (`src/uiext.c`), but tables resolve most strings by index at load,
  so a fix at the lookup misses them. Replacing the whole cooked string
  table when it loads is the reliable route; the format is simple enough
  to write.
- **Extra pak (confirmed 2026-09-23):** the exe mounts every
  `data\<prefix><family>*.idx` for the prefixes "", `x_`, `sp_` and `mp_`
  (`FUN_00426795`, pattern `%s%s*.%s`; `sp_` mounts after the stock paks),
  and `FUN_0042667b` accepts a name only if what follows the family is
  digits, `_` and `.`: `sp_hellgate_localized_1337` loads,
  `sp_hellgate_localized_ultra` does not. Stock patches were appended as
  newer copies of the same path (636 paths in `hellgate_localized000` have
  2–4 copies), and a copy in our pak with a current file time wins: a
  `strings_strings` with "[PAK] " before three labels showed "[PAK] Options"
  on the main menu. `tools/data/hgpak.py` writes such a pak and
  `tools/data/hgstrings.py` the string tables (all 27 tables of both builds
  round-trip byte for byte). So every file drop above (movies, textures,
  strings, tables) is data only, with no DLL change, and Steam's verify
  ignores the extra files.
- **Lookups are per family.** A path resolves within the pak family that
  asked for it: the HD intro under the `_low` name did nothing from
  `sp_hellgate_movieshigh_*` and played from `sp_hellgate_movieslow_*`. An
  override goes in the family of the stock file it replaces.
- **Otherwise** a DLL hook on the pak read gives a generic
  `override\<pak path>`, as `.fxo` and UI XML have today.
- **Flags** (event quests, vendors) are byte patches of a table or of the
  loaded row. **New rows** (the Flagship logo, Temple levels) need an excel
  writer; Reanimator-steam's needs .NET, which the host lacks.

## Shipped: `make paks`

`tools/data/mkpaks.py` builds three paks into `<game>/data/` (suffix `_2337`;
`_1337` is the one Reanimator-based mods use), and `make uninstall` removes
them. Confirmed in game 2026-09-23.

- **HD movies.** The movie player (`FUN_004b6552`, `c_movieplayer.cpp`)
  takes the row's low file first whenever the platform caps read low
  (`DAT_00eda0fc < 400` or `DAT_00eda100 < 1700`, filled by
  `FUN_007e6abf`), which they do under Proton, and only then considers the
  high file (row flag `forceAllowHighQuality` or the SKU's
  `lowQualityMoviesOnly` clear). So the paks answer the `_low` names with HD
  bodies: the 2007 story movies (1920×1088) in `sp_hellgate_movieslow_2337`,
  the 2007 end credits (1680×1056) and 2018's own menu backgrounds
  (`titlescreen_high` 1600×1200, `titlescreen_wide_high` 1920×1088, played
  at 640×368 before) in `sp_hellgate_movies_2337`. Each body is stored once
  and named twice.
- **No HanbitSoft logo.** `sp_hellgate_2337` carries `movielists.txt` with
  movie 34 (`LogoHanbitSoft`) dropped from every list, and `sku.txt` with
  `lowQualityMoviesOnly` cleared, both patched in place (same size) from the
  newest stock copy.
